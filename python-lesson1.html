    1. What is Python?

    Python is a programming language — strict rules for instructions the computer follows exactly, line by line, in order. If you forget a step, the program keeps going the wrong way even when your intention was obvious.

    Analogy: giving directions to a boda rider. Every turn must be stated. Python is readable, free, cross-platform, and widely used for web, data, automation, and learning.

    2. Install Python (step-by-step)

    1. Open terminal (Command Prompt on Windows, Terminal on Mac).
    2. Run python3 --version or python --version.
    3. If missing: download from python.org/downloads.
    4. On Windows: tick Add Python to PATH before Install.
    5. Close and reopen terminal; run the version command again.
    Common fix: “python is not recognized” → reinstall with Add to PATH checked.

    3. Install VS Code + Python extension

    1. Download VS Code from code.visualstudio.com.
    2. Open Extensions (four squares), search Python, install Microsoft’s official extension.
    3. Create a folder for your work; open it in VS Code.

    4. Your first program

    print("Hello, Digital Bridge!")
print("My name is [your name]")
print("I am learning Python!")

    Save as hello.py. Run via Run Python File in Terminal or the green play button. Each print() shows on its own line.

    5. Understanding print()

    print() is a built-in function. Text inside must be a string in quotation marks. You will use print() heavily until you learn variables in Lesson 2.

    6. Read errors without fear

    Break code on purpose to learn:

    print("Hello, Digital Bridge!)   # missing closing quote
Print("Hi")                     # wrong capital P

    Read the error slowly. Note the line number. Python is case-sensitive: print ≠ Print.

    8. Independent practice — ten problems

    Complete each in its own .py file. Use the Class Activity form to paste code or output and submit to your teacher.

    1. Print full name on one line, town on the next.
    2. Print numbers 1–5 using five separate print() calls.
    3. Print a 3-line shopping list (one item per line).
    4. Print a favourite quote, then who said it on the next line.
    5. Remove a quotation mark on purpose, read the error, fix it.
    6. Misspell print as prit, read the error, fix it.
    7. Print a small 3×3 box using only #.
    8. Print Monday through Sunday (seven lines).
    9. Print a two-line joke (punchline on line 2).
    10. Challenge: ASCII smiley with characters like : ).
