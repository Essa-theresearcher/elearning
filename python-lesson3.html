    Jump to Week 3 lab

    1. Comparisons give True or False

    age = 20
print(age >= 18)   # True
print(age == 17)   # False

    Operators: == equal, != not equal, < > <= >=. Do not use = for comparison.

    2. if / else

    score = 55
if score >= 50:
    print("Pass")
else:
    print("Retake")

    Indented lines belong to the block. Only one branch runs.

    3. elif chains (grade ladders)

    Check conditions top to bottom. First true branch wins; rest are skipped.

    mark = 72
if mark >= 80:
    print("A")
elif mark >= 60:
    print("B")
else:
    print("C")
    Trace habit: For mark 72, which lines are tested? Which print runs?

    4. Combining conditions

    and — both must be true. or — at least one true. not flips boolean.

    age = 16
has_id = True
if age >= 18 or has_id:
    print("Enter")

    5. input() + decisions

    pwd = input("Password? ")
if pwd == "dba2026":
    print("Welcome")
else:
    print("Denied")

    Compare strings with ==. Remember input returns text.

    6. Common mistakes

    • Using if x = 5: instead of ==
    • Wrong indentation (SyntaxError or wrong branch)
    • elif order too loose (e.g. checking >= 60 before >= 80)

    TermMeaning
