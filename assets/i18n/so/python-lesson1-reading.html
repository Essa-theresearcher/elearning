1. Waa maxay Python?

Python waa luqad barnaamijeed — xeerar adag oo tilmaamaha kombiyuutarku raaco sida saxda ah, saf saf, si taxane ah. Haddii aad tillaabo ka maqto, barnaamijku wuu sii socdaa qaldan xitaa haddii ujeeddadaadu ay caddayd.

Isbarbardhig: sida tilmaamaha boda wadaha. Isku rog kasta waa in la sheegaa. Python waa mid akhriska fudud, bilaash ah, meelo badan ka shaqeeya, waxaana loo isticmaalaa web, xog, otomaatig, iyo barashada.

2. Rakib Python (tallaabo tallaabo)

  1. Fur terminal (Command Prompt Windows, Terminal Mac).
  2. Orod python3 --version ama python --version.
  3. Haddii aan jirin: ka soo dejiso python.org/downloads.
  4. Windows: calaamadee Add Python to PATH ka hor Install.
  5. Xir oo dib u fur terminal; mar kale orod amarka nooca.
Hagaajin caadi ah: “python is not recognized” → dib u rakib oo PATH calaamadee.

3. Rakib VS Code + kordhinta Python

  1. Ka soo dejiso VS Code code.visualstudio.com.
  2. Fur Extensions (afar laba jibbaaran), raadi Python, rakib kordhinta rasmiga ah ee Microsoft.
  3. Samee galka shaqadaada; ka fur VS Code.

4. Barnaamijkaaga ugu horreeya

print("Hello, Digital Bridge!")
print("My name is [magacaaga]")
print("I am learning Python!")

Kaydi hello.py ahaan. Orod Run Python File in Terminal ama badhanka cagaaran. print() kasta wuxuu ku soo baxaa saf gaar ah.

5. Fahamka print()

print() waa function dhismeed ah. Qoraalka gudaha waa inuu ahaadaa string oo ku jira calaamadaha xarafeed. Waxaad si weyn u isticmaali doontaa print() ilaa aad barato doorsoomayaasha Casharka 2.

6. Akhri khaladaadka cabsi la’aan

Si ula kac ah u jebi koodh si aad u barato:

print("Hello, Digital Bridge!)   # calaamad xiran maqan
Print("Hi")                     # P weyn qaldan

Si tartiib ah u akhri qaladka. Eeg lambarka safka. Python waa case-sensitive: print ≠ Print.

8. Tababar madaxbannaan — toban dhibaato

Dhammaystir mid kasta fayl .py gaar ah. Isticmaal foomka Hawlaha fasalka si aad u gudbiso macallinka.

  1. Daabac magaca buuxa hal saf, magaalada safka xiga.
  2. Daabac tirooyinka 1–5 shan print() oo gooni ah.
  3. Liiska iibsiga 3 saf (shay kasta saf).
  4. Daabac xigasho, qofkii yidhi safka xiga.
  5. Ka saar calaamad xarafeed si ula kac ah, akhri qaladka, hagaaji.
  6. Qor prit halkii print, akhri qaladka, hagaaji.
  7. Sanduuq 3×3 oo # kaliya.
  8. Isniin ilaa Axad (todoba saf).
  9. Sheeko laba saf (line 2 punchline).
  10. Caqabad: ASCII smiley.

9. Shaqada guriga

  • Hubi Python iyo VS Code guriga (ama qor meesha aad tababaran karto).
  • Dhammaystir dhibaatooyinka madaxbannaan ee ka haray fasalka.
  • Qor barnaamij ugu yaraan lix print() oo naftaada ku soo bandhigaya.
  • Ikhtiyaari: ASCII art madaxa.
