1. Doorsoomayaasha waxay kaydiyaan qiimo (sida Practical Axad)

Doorsoome waa magac qiimo loo bixiyey. = waa “hel”, ma aha “is le’eg”. Python waxay orodisaa saf saf; qoondee kasta waxay beddeli kartaa qiimaha.

score = 10
score = score + 5
print(score)   # 15

Caado saadaalin: Ka hor orodka, sheeg qiimaha doorsoomaha kadib saf kasta.

3. String-yada iyo tirooyinka (Practical Isniin)

"5" waa qoraal; 5 waa tiro. Isku dar qoraalka + ama f-string; xisaab tirooyinka kaliya.

4. input() had iyo jeer string ayay soo celisaa

name = input("Magac? ")
age = int(input("Da'? "))

U beddel int() ama float() ka hor xisaabinta.

5. Shaxda beddelka nooca

  • int("12") → 12
  • float("3.5") → 3.5
  • str(100) → "100"

6. f-strings warqadaha rasiidka
