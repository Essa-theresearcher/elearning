1. Maxaa loo isticmaalaa loop?

Loop-yadu waxay ku celiyaan koodh ilaa shuruud la gaaro ama liis dhammaado — ma aha inaad isku qorto boqolaal saf.

2. while loops (Practical Talaado)

count = 3
while count > 0:
    print(count)
    count = count - 1

Hubi in shuruuddu mar uun noqoto False si aanu weligeed u sii socdo.

3. for iyo range()

for n in range(1, 6):
    print(n)

range waxay xukumaa inta jeer ee la ordo.

5. while vs for

for marka aad ogtahay tirada; while marka aad sugto shuruud.

6. break iyo loop + go’aanno
