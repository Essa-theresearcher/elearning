1. Isbarbardhigyo → True ama False

==, !=, <, > waxay soo saaraan True ama False. Saadaali natiijada ka hor if.

2. if / else — hal waddo ayaa orda

score = 72
if score >= 50:
    print("Pass")
else:
    print("Try again")

Kaliya laamaha run ah ayaa la fuliyaa.

3. elif — jaranjarada (darajo, tigidh)

Akhri if / elif kor ilaa hoose; jooji marka shuruud run noqoto.

4. and / or / not

Isku dar shuruudaha si aad u qaabeyso xeerar adag.

5. input() + go’aanno

Marka hore u beddel nooca, kadib isbarbardhig tiro ahaan.

6. Go’aanno isku xidhan (hordhac dhexdhexaad)

if gudaha if — indentation waa muhiim.
