Capstone project — “Academy Service Desk”

Covers Weeks 1–5 · Individual project · Suggested time: 1–2 weeks outside class

Project story

Digital Bridge Academy needs a small terminal program for teachers: manage a list of students, print a canteen receipt, and save data to a file when the program exits. One running program with a repeating menu; no GUI required.

Part A — Brief answers

  1. Interpreter runs Python line by line; .py is source code.
  2. Case-sensitive: built-in is print, not Print (NameError).
  3. Text in quotes, e.g. print("hello").
  4. SyntaxError (quotes/colons); NameError (wrong name).
  5. Three lines: A, B, C.
  6. Always a string.
  7. "5" str vs int 5; different types.
  8. Can't concat str + int; use f-string or str(50).
  9. 15.
  10. e.g. f"{qty} x {item} = {qty * unit}".
  11. = assign; == compare.
  12. First match wins; elif stops overlap (90 must hit A not C).
  13. AND both true; OR at least one.
  14. Check raw == "" before int().
  15. Grade C (59≥50, <60).
  16. input returns "1" str; compare "1" or use int.
  17. Condition never false; update counter toward exit.
  18. 1,2,3,4,5 — not 6.
  19. Running total/count; init before loop.
  20. Exits loop (e.g. quit).
  21. append; for x in names:.
  22. 2.
  23. print displays; return gives value to caller.
  24. Parameters/return clearer and safer.
  25. student["grade"].
  26. Returns default 0, no KeyError.
  27. Closes file automatically.
  28. Non-numeric input to int().
  29. Typical: input → convert → loop menu → if branches → functions → save on exit.
  30. e.g. valid number, empty, letters.
  31. if inside for (pass count).
  32. Functions for add/find/save.
