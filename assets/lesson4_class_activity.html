How Web Applications Actually Work

Practice tracing a real web app flow from screen to backend to database and back.

1Architecture Map

Draw or describe frontend, backend, database, and proxy for the LMS.

GuidanceA good architecture map shows both the path of traffic and where data is stored.

2Request Trace

Trace one button click from the page to the backend and back.

GuidanceEvery web app feature is easier to debug when you can trace the request and response.

3Permission Check

Say what a student, teacher, and admin should each be allowed to do.

GuidanceRoles must be enforced by the backend, not only hidden in the browser UI.

4Environment Variables

List three environment variables and what they control.

GuidanceEnvironment variables let production use real secrets and service addresses without changing code.

5Domain Debugging

Write a checklist for when a domain is not opening.

GuidanceChecking in layers prevents random changes that break other apps on the VPS.
