Week 0 Coding Review

Python readiness coding prompts

Submit real Python work that shows how you write, test, debug, and explain small programs.

Coding review brief

Complete the prompts below in Python. The goal is not to produce a huge project. The goal is to show that you can write functions, use Python data structures, reason about classes, handle files, and explain your debugging process.

The submitted work should include:

  • A function that accepts a list of scores and returns a dictionary with the average, highest score, lowest score, and pass/fail label.
  • A string-cleaning function that normalizes names or email addresses using methods such as strip, lower, split, or slicing.
  • A list or dictionary comprehension that filters or transforms data.
  • A small class with __init__, at least two attributes, and one useful method.
  • A short file I/O example or a written explanation of how their code would read from and write to a text file.
  • A try/except example that handles bad input without crashing.

Suggested 90-minute timeline

  • 20 minutes: write the score-analysis function and test it with at least two lists.
  • 15 minutes: write the string-cleaning function.
  • 15 minutes: add a comprehension that filters or transforms a list.
  • 20 minutes: create the class and call its method.
  • 10 minutes: add file I/O or explain the exact file I/O plan.
  • 10 minutes: write the debugging reflection.

Required evidence

The submission should show your design choices, working Python, and a reflection on one mistake or improvement.

Example direction

def summarize_scores(scores):
    average = sum(scores) / len(scores)
    return {
        "average": average,
        "highest": max(scores),
        "lowest": min(scores),
        "label": "ready" if average >= 75 else "review"
    }

Rubric

Ready

Code runs, functions return useful values, data structures are appropriate, and explanations are clear.

Almost ready

Code partly works and shows real reasoning, but one core idea such as classes, comprehensions, files, or errors needs review.

Needs foundations

No working attempt, no clear logic, no debugging evidence, or no explanation of what the code does.
