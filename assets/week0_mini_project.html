Week 1 Mini Project

Readiness report tool

Build a small program that turns a student's skill evidence into a readiness recommendation.

Project brief

Create a small program called readiness_report. It can be written in Python or JavaScript. The program should store a learner profile, evaluate several skill areas, and print a final recommendation.

Your program should include:

  • A profile with name, goal, claimed level, and available study hours.
  • A list or dictionary of at least five skill areas.
  • At least one function that receives data and returns a useful result.
  • A loop that evaluates all skill areas.
  • A conditional that decides between ready, almost ready, and needs foundations.
  • Clear output that a teacher could read quickly.

Suggested build timeline

  • 30 minutes: sketch the profile fields, skill areas, and readiness rules before writing code.
  • 45 minutes: build the first working version with hard-coded sample data.
  • 30 minutes: add a function that calculates an average and another function that returns the placement label.
  • 30 minutes: test the program with three different profiles: ready, almost ready, and needs foundations.
  • 30 minutes: improve the output so a teacher can understand the recommendation quickly.
  • 15 minutes: write the reflection and submit the strongest code sample.

Required evidence

The submission should prove that the student did not only copy a finished answer. It should show design choices, a useful function, a loop, data structure use, and a reflection on one mistake or improvement.

Example shape

profile = {
    "name": "Amina",
    "claimed_level": "intermediate",
    "weekly_hours": 8
}

skills = {
    "functions": 4,
    "loops": 3,
    "debugging": 2,
    "data_structures": 4,
    "web_basics": 3
}

def average_score(skill_scores):
    total = 0
    for score in skill_scores.values():
        total += score
    return total / len(skill_scores)

Rubric

Ready

Program runs, logic is organized, output is readable, and the student can explain the result.

Almost ready

Program partly works and shows real reasoning, but one core idea such as functions or dictionaries needs review.

Needs foundations

No working attempt, no clear logic, no debugging evidence, or no explanation of what the code does.
