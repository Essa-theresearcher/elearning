Getting Started with Python — Full Lab

Work through setup, guided practice, and ten independent problems. Type real code in VS Code on your machine, then paste outputs or reflections here before you submit.

Plan 60–90 minutes · Python 3 + VS Code required · Save each program as its own .py file

Phase A — Environment setup

AInstall and verify

Complete every step on your own computer. Ask for help only after you try twice.

Phase B — Guided practice (do together, then alone)

1Three-line introduction

Write three print() lines: your name, age, favourite food. Run in VS Code.

2Predict the output

print("I love") print("Python") print("programming")
Three separate lines: I love · Python · programming — each print() starts a new line.

3Fix the missing quote

print("Karibu Digital Bridge)
print("Karibu Digital Bridge") — closing quotation mark was missing (SyntaxError).

4Fix the extra bracket

print("Hello World"))
print("Hello World") — one extra ) caused a syntax error.

5Text poster (5+ lines)

Use only print() to advertise Digital Bridge Professional Skills. Include a border with * or =.

6Case sensitivity

Print("Wrong capitalisation")
NameError: name 'Print' is not defined — Python treats print and Print as different names.
