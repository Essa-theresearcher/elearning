0. Why loops?

Week 3 menus run once then stop. Real apps repeat until the user quits. Loops run a block many times while a condition holds (while) or for each item in a sequence (for).

Step-by-step: spot when you need a loop

  1. Underline words like “each”, “until”, “repeat”, “for every student”.
  2. Count how many times — fixed number → often for; unknown until event → often while.
  3. Identify what changes each time (counter, item in list, user guess).
  4. Write the stop rule in English before coding (infinite loops = missing update).

Step-by-step: write your own countdown

  1. Start n = 10.
  2. while n > 0:
  3. Print n, then n -= 1 (must change n toward false condition).
  4. After loop, print "Lift off".
  5. Test: output 10 down to 1 then Lift off.

2. Infinite loop mistakes — how to fix

If the condition never becomes false, the program runs forever (stop with Ctrl+C in terminal).

Step-by-step debug

  1. Find the variable in the while condition.
  2. Confirm the loop body updates that variable toward False.
  3. Add temporary print of the variable inside the loop to watch it change.

3. for loops and range()

for i in range(5):
    print(i)          # 0,1,2,3,4

for n in range(1, 6):
    print(n)          # 1,2,3,4,5

Step-by-step: read range(a, b)

  1. Start at a.
  2. Go up by 1 each time.
  3. Stop before b (never prints b).

Step-by-step: 5 times table

  1. for n in range(1, 13):
  2. print(f"5 x {n} = {5 * n}")
  3. Verify first line 5 x 1 = 5 and last 5 x 12 = 60.

4. Accumulators — sum, count, average

Pattern: initialize before loop → update inside → use after.

total = 0
count = 0
for _ in range(5):
    mark = int(input("Mark? "))
    total += mark
    count += 1
print("Average:", total / count)

Step-by-step: build average of 5 marks

  1. Before loop: total = 0, count = 0.
  2. Loop exactly 5 times (or until user quits — your choice).
  3. Each time: read mark, add to total, increment count.
  4. After loop: divide total by count (only if count > 0).
  5. Test with five known marks on paper first; compare to program output.

6. break — leave the loop early

secret = 7
while True:
    guess = int(input("Guess 1-10: "))
    if guess == secret:
        print("Correct!")
        break
    print("Try again")

Step-by-step: guessing game core

  1. Store secret number (fixed or random later).
  2. while True — intentional infinite loop controlled by break.
  3. Read guess, compare with Week 3 if.
  4. On success: message + break.
  5. On fail: hint, loop continues.
