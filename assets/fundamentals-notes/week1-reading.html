0. Mindset — the computer is literal

Python does not understand your intention — only what you typed, in order, with correct spelling and punctuation. That feels strict at first; it is why programming becomes predictable once you learn the rules.

Step-by-step: your first session (15 minutes)

  1. Open VS Code and your course folder (create python_week1 if needed).
  2. Confirm Python works (section 2) — do not skip.
  3. Create hello.py with exactly three print() lines from section 4.
  4. Run once; if error, read section 6 before changing random lines.
  5. Write in notebook: “Today I ran my first program and saw ___ on the screen.”
Analogy: Python is like directions to a boda rider — every turn must be stated. “Go to town” is not enough; “Turn left at the mosque” is code.

1. What is Python?

Python is a programming language: rules for writing instructions the computer follows. An interpreter reads your .py file line by line and executes it.

Step-by-step: explain Python to a friend

  1. Say: “I write text in a file ending in .py.”
  2. Say: “Python reads it top to bottom.”
  3. Say: “Each line is one instruction, like print("Hi").”
  4. Mention one use: websites, data, automation, learning — you are learning the foundation used everywhere.

Free and cross-platform: Same ideas on Windows, Mac, and Linux. Your code travels with you if you save files in the cloud or USB.

2. Install Python (step-by-step)

  1. Open Terminal (Mac) or Command Prompt (Windows).
  2. Type python3 --version or python --version and press Enter.
  3. If you see Python 3.x.x, skip to section 3.
  4. If “not recognized”: go to python.org/downloads, download Python 3.
  5. Windows only: on the installer first screen, tick Add Python to PATH, then Install.
  6. Close terminal completely; open a new one; run the version command again.
Common fix: “python is not recognized” → reinstall with Add to PATH checked, or use py -3 on Windows.

Verify in VS Code terminal

  1. VS Code → Terminal → New Terminal.
  2. Run the same version command inside the project folder.
  3. Notebook check: write the version number you saw.

3. Install VS Code + Python extension

Step-by-step

  1. Download VS Code from code.visualstudio.com.
  2. Open VS Code → Extensions icon (four squares) → search Python → install Python by Microsoft.
  3. File → Open Folder → choose your python_week1 folder.
  4. File → New File → save as hello.py immediately (Python extension activates for .py files).

Why a folder? All week’s programs stay together; easier to submit and backup.

4. Your first program — line by line

print("Hello, Digital Bridge!")
print("My name is Amina")
print("I am learning Python!")

Step-by-step: create and run

  1. Save file as hello.py (not hello.py.txt — hide extensions if Windows adds .txt).
  2. Click Run Python File in Terminal (play icon) or right-click editor → Run.
  3. Watch the Terminal panel at bottom — output appears there, not in the editor.
  4. Expect three lines of text, one per print.
  5. Change the second line to your real name; run again.

Order matters: Python runs line 1, then 2, then 3. It never runs line 3 before line 1.

5. Understanding print() and strings

print() is a built-in function. The text you show must be a string: characters inside matching quotation marks "..." or '...'.

Step-by-step: read one print line

  1. Find the word print — lowercase p.
  2. Parentheses ( ) hold what to display.
  3. Inside quotes is literal text — spaces and punctuation print exactly.
  4. Python adds a newline after each print (next print starts on a new line).
print("Line one")
print('Line two')   # single quotes also work
print("Score:", 100)  # comma: space between parts (preview Week 2)

Practice 5.1

Predict output on paper for three prints: "I love", "Python", "programming". Then run — confirm three separate lines.

6. Read errors without fear

Errors are messages, not failure. They point to line number and problem type.

Step-by-step: fix a SyntaxError (missing quote)

  1. Type on purpose: print("Hello, Digital Bridge!) — missing closing ".
  2. Run — read red text in terminal.
  3. Find SyntaxError and the line number (often the line with the mistake).
  4. Add the closing quote before ).
  5. Run again — error gone.

Step-by-step: fix NameError (wrong spelling)

  1. Type Print("Hi") — capital P.
  2. Run — NameError: name 'Print' is not defined.
  3. Python is case-sensitive: only print exists.
  4. Fix to print("Hi").
ErrorUsually means
SyntaxErrorMissing quote, bracket, or colon
NameErrorMisspelled name (Print, prit)
IndentationErrorWrong spaces (more in Week 3)

7. Comments — notes for humans

Lines starting with # are ignored by Python. Use them for your name, date, and what the program does.

# Week 1 — Amina — intro poster
print("Digital Bridge Academy")
print("Python Week 1")

Step-by-step

  1. Line 1: # + description.
  2. Never put code you need to run after # on the same line unless after the code: print("Hi") # greeting.
