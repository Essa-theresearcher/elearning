1. Why functions?

Copy-paste causes bugs: fix one copy and forget the other. A function is a named recipe.

Step-by-step: first function

  1. Create greet.py.
  2. Line 1: def greet(name):
  3. Indented: return f"Hello, {name}"
  4. Unindented: print(greet("Amina"))
  5. Run — expect Hello, Amina.
  6. Change only the argument in the call — body unchanged.
def greet(name):
    return f"Hello, {name}"
print(greet("Amina"))

2. return vs print

print shows text; return gives a value to the next line of code.

Step-by-step: VAT function

  1. English: "VAT is 16% of amount."
  2. def vat(amount, rate=0.16): return amount * rate
  3. bill = 1000 + vat(1000)
  4. Print bill — trace: vat returns 160, bill 1160.
  5. Test with amount 500 on paper then in code.
def vat(amount, rate=0.16):
    return amount * rate
total = 1000 + vat(1000)

Each: English → def → return → three test calls. Functions: area, perimeter, c_to_f, pass_fail, discount, full_name, count_vowels, is_even.

3. Scope — local vs global

Step-by-step: see scope

  1. Inside function: x = 5 — local to function.
  2. Outside function: different x — not the same variable.
  3. Rule: pass data in parameters; return results — avoid global as a beginner.

4. Docstrings

Step-by-step

  1. First line inside function: """One sentence what it returns."""
  2. Reader (and future you) knows purpose without reading body.
def fee(base, member):
    """Return final fee; members get 10% off."""
    if member:
        return base * 0.9
    return base

10. Functions that change data structures

def add_student(students, record):
    students.append(record)

def find_student(students, sid):
    for s in students:
        if s["id"] == sid:
            return s
    return None

Step-by-step test

  1. Empty list, call add twice, call find with existing and missing id.
  2. Print results — expect dict or None.

13. try / except — safe int input

Step-by-step

  1. Wrap int(input(...)) in try.
  2. except ValueError: print friendly message, skip or retry.
  3. Test: type abc, then type 12.
try:
    age = int(input("Age? "))
except ValueError:
    print("Please enter a number")
    age = 0

14. Common errors — fix method

  1. KeyError: use .get or check key in dict.
  2. None from function: forgot return.
  3. FileNotFoundError: wrong path — print cwd or use same folder as script.
