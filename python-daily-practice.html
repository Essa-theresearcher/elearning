    Python Practical — daily problem-solving practice

    This course is separate from Python Fundamentals. The goal is to perfect Python thinking: predict output, write code under test, debug with a coach, and repeat until patterns stick. Plan for 60–75 minutes of focused practice most days.

    Each day you get a full workout: 8 predict challenges, 5 coding tasks at your level, and 3 visual stages — Beginner, then Intermediate, then Advanced. Miss a day in the week and that day locks — stay consistent.

    Daily rhythm (~60–75 min): Predict & Reason (~25) → Write Code (~25) → Visual Play (~20) → Today's log (~5). Replay quests for extra reps after you finish once.

    Critical thinking steps (every activity)

    1. Understand: Say the goal in your own words before you touch the keyboard.
    2. Plan: Write or sketch the steps — not the full answer yet.
    3. Try: Make one small attempt and observe what happens.
    4. Compare: What did you expect vs what actually happened? That gap is the lesson.
    5. Adjust: Change one thing, test again; use hints only after step 4.

    When an answer is wrong

    Every quest and lab shows a step-by-step coach — not just “incorrect.” Use it to train problem solving, not to rush to the right letter.

    1. Name what you thought would happen.
    2. Name what the program actually does on the failing line.
    3. Fix or rule out one option with a reason.
    4. Try again, then open a hint if you are still stuck.

    Program weeks (1–5)

    Five weeks of daily practice, aligned with Python Fundamentals Weeks 1–5. Complete all 7 days (Sun–Sat) to unlock the next program week. Calendar days still lock if you skip.

    This calendar week (Sunday → Saturday)

    Work in order from Sunday through Saturday. If you skip a day, that day locks. Content follows your program week above (not the same every calendar week). Visual stages: Beginner → Intermediate → Advanced.

    Flexible schedule: You can work any day Sun–Sat that has already started this week (catch up on Sun, Mon, Tue, Wed, and so on). Skipped days are not locked. Future days stay closed until that date.

          Visual Play — today’s game

          Three visual stages each day: Beginner (Snake), then Intermediate (Maze), then Advanced (Sudoku). The challenge changes by weekday. Finish all three in the tabs to check off visual practice.

          Finish Write Code first, then complete all three visual games below.

          How to tackle visual labs

          1. Draw the grid: head, food, and body cells.
          2. Decide: move toward food or avoid a crash?
          3. Change one rule in choose_direction, test, then run the game.
          4. When Snake, Maze, or Sudoku stops you, read Where to look. It names the cell, row, or line and why. A check or cross marks each part. The full answer stays hidden.
          5. Hint has three steps: the idea, the spot, then nearly the answer. Hints cost stars on the quests and on Sudoku. You can always finish.

          Finish all three games in order for your selected day, then mark Visual Play complete.
